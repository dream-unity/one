Look inside the experiment

The rules are part of the world.

What the lights mean

Island 1 is the source. A light turns on if an unbroken path connects it to the source. Bridges work both ways. Travel follows a shortest path measured in bridge crossings.

The nine island positions are fixed. A bridge costs its straight-line length divided by 12, rounded to the nearest whole stone, with a minimum of one. Every world has 42 stones.

What a test does

We test every possible single bridge failure, every non-source island failure, or every pair of bridge failures. Each trial begins with the original world. The worst result is the fewest lights connected in any trial.

With a sleeping island there are eight possible lights; the source stays awake. Disconnected islands count as dark. A world with too few bridges to run the chosen test has no result.

How an idea grows

After a test, “Grow a new idea” tries every legal one-bridge addition and removal. It prefers more lights in the worst trial, then more on average, then fewer stones, then shorter journeys. It keeps a record of the parent world.

This local search is a small, inspectable rule. It may get stuck: a better world might need several changes at once. You can make those changes yourself.

What we can learn

These are exact results for this small graph model. Bridge stones are game units. We do not model physical strength, traffic, electrical circuits, people or intelligence. A good game result does not establish a claim about those things.

A and B use the same islands, source, budget limit and failure rule. Their bridge counts and costs can differ. The comparisons show those differences.

Sharing & memory

Your notebook is saved in this browser when storage is available. Export it for a separate copy. Shared links contain the world’s name, idea, creator, bridges and parent IDs. They contain no notebook history.

Atlas submissions open on GitHub for you to review and publish. Their contents and GitHub account are public. Shared designs can be checked and added to the atlas; their results are recalculated from their bridges.
